# 🚁 Fly-in

## **Description**

Fly-in is a drone routing system project where we build a complete system to manage drone movement across multiple paths. The goal is to route drones from a start point to an end point efficiently.

The project uses turn-based scheduling and pathfinding algorithms to control drone movement while respecting constraints. It also provides a graphical interface using a GUI library such as raylib to visualize the simulation.

---

## **Instructions**

To run the project:

```bash
make install   # install dependencies
make run       # build and run the project
```

Make sure to run `make install` first to ensure all project dependencies are installed.
